# Gaia · demonstração web

Este repositório publica apenas a **versão web compilada** do protótipo funcional da Gaia, um app de gestão financeira pessoal (nome provisório), no GitHub Pages: https://bielbaeta.github.io/gaia-app/

- É uma **demonstração**: roda sem conta e sem back-end, com três cenários fictícios (Ana, Bruno e Carla). Nenhum dado real é coletado.
- O código-fonte, a pesquisa e a documentação ficam em um repositório privado. O conteúdo deste repositório é gerado automaticamente pelo script de deploy a partir dele (branch `gh-pages`).
- Nada aqui é recomendação de investimento.
